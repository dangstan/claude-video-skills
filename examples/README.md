# Examples

**This tree is being regenerated and is empty on purpose.**

Every document that used to live here has been removed. They were real run outputs, but they were
not all *one clean run of one skill on one video*, and that is the only thing an example is for:

- Two were second passes written knowing what an earlier pass had said. One of them left whole
  required sections unmeasured because the earlier pass already had them -- a shape no clean run
  produces.
- Others had accumulated edits after the fact: publication scrubs, coarsened quasi-identifiers,
  defect notes added editorially. Each edit was justified on its own terms, and the cumulative
  effect was a set of documents whose provenance a reader could not reconstruct.

The replacement is a fresh run of all three skills against the same three sources, each run with no
knowledge of any earlier run of that source, published as produced apart from the sanitization the
private recording requires. The three sources are unchanged:

| Source | what it is |
|---|---|
| `tech-interview-screen` | a real 31m32s screening interview -- private recording, to be anonymized, transcript withheld |
| `founder-interview-podcast` | a published founder interview, [youtu.be/utb7zYbK10c](https://youtu.be/utb7zYbK10c) |
| `harness-comparison-explainer` | a published solo explainer, [youtu.be/UsfCe5fJK6A](https://youtu.be/UsfCe5fJK6A) |

`video-autopsy` against the explainer is expected to refuse on its MODE 1 scope gate rather than
produce a deliverable. That refusal is a result, and it ships.

Until the new runs land, the skills themselves are the documentation: each package's `SKILL.md`
states what it produces and `preflight.sh` states what it refuses.
